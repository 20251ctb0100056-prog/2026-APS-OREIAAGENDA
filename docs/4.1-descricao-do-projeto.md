# 4.1 Descrição do Projeto

## O problema, na voz do cliente

> *"No balcão, preciso organizar os horários dos serviços dos pets, porque quando os agendamentos são feitos manualmente pode acontecer de marcar dois atendimentos no mesmo horário ou esquecer alguma informação."* (Luiz Carlo, responsável pelo balcão)

## Propósito

O sistema tem como propósito organizar os atendimentos do pet shop e evitar conflitos nos horários dos serviços.

## Objetivo

O objetivo do sistema é permitir o cadastro de pets, responsáveis e serviços, além de organizar e consultar os agendamentos do pet shop.

## Quem usa

* **Atendente do balcão.** Cadastra pets e responsáveis, registra serviços e organiza os agendamentos.
* **Responsável pelo pet.** Informa os dados do pet e solicita o agendamento de um serviço.

## Escopo

* O sistema **cadastra pets**.
* O sistema **cadastra responsáveis**.
* O sistema **cadastra serviços**.
* O sistema **registra agendamentos**.
* O sistema **consulta horários agendados**.
* O sistema **cancela agendamentos**.

## Fora do escopo

* **Pagamento dos serviços**, porque o projeto não terá integração com sistemas de pagamento.
* **Controle de estoque**, porque o foco do sistema é organizar os atendimentos.
* **Controle financeiro**, porque não é necessário para resolver o problema dos agendamentos.
* **Notificações por WhatsApp ou SMS**, porque seriam necessárias integrações com serviços externos.

## Características principais

O sistema será simples de utilizar e permitirá visualizar os agendamentos por data e horário. Também deverá evitar conflitos de horários e facilitar o acesso às informações dos pets, responsáveis e serviços.
