## 4.2.3 Modelagem de Classes

Esta seção apresenta a estrutura de classes do sistema de **Agenda de Pet Shop**, focada nos dados e nas principais ações do sistema.

---

### 1. Tabela de Identificação

| Substantivo | Vira o quê? | Por quê? |
| :--- | :--- | :--- |
| **Cliente** | **Classe** | Guarda os dados de quem contrata o serviço. |
| **Pet** | **Classe** | É o animal que vai ser atendido (espécie, raça). |
| **Agendamento** | **Classe** | Guarda a data, hora e liga o cliente ao pet e serviço. |
| **Serviço** | **Classe** | Define o que vai ser feito (banho, tosa) e o preço. |
| **Funcionário** | **Classe** | Quem vai realizar o atendimento no pet shop. |
| **Nome / Telefone** | Atributo | Detalhes que pertencem ao cadastro do Cliente. |
| **Data / Hora** | Atributo | Detalhes que pertencem ao Agendamento. |

---

### 2. Classes e Atributos Principais

* **Cliente:** `idCliente`, `nome`, `telefone`, `email`
* **Pet:** `idPet`, `nome`, `raca`, `porte`
* **Agendamento:** `idAgendamento`, `data`, `hora`, `status`
* **Serviço:** `idServico`, `nomeServico`, `preco`
* **Funcionário:** `idFuncionario`, `nome`, `cargo`

---

### 3. Diagrama de Classes (Resumo das Ligações)

* **Cliente** possui `1..*` **Pets**.
* **Cliente** realiza `0..*` **Agendamentos**.
* **Pet** participa de `0..*` **Agendamentos**.
* **Agendamento** inclui `1..*` **Serviços**.
* **Funcionário** executa `0..*` **Agendamentos**.

### 4. Rastreabilidade Básica

* O cadastro do **Pet** atende ao fluxo de inserir o animal do cliente.
* O **Agendamento** valida a data e o horário escolhido.
* O **Serviço** calcula o valor total cobrado no atendimento.
